About Weight Classes

Weight classes define the size options for your cakes. Each cake can have different prices for different weight classes. For example, a Cream cake might cost:

  • 1 Pound: Rs. 1,800
  • 2 Pound: Rs. 3,500
  • 3 Pound: Rs. 5,000
Important Note

Deleting a weight class will also remove all associated pricing for cakes. Make sure to update your cakes before deleting any weight class that is currently in use.
